1. 🪧 The Beginning — “I want to know.”

कौतूहल is the permanent name of the guild. Its simplest meaning is:

“I want to know.”

Curiosity here isn't just watching videos, collecting facts, or saying “that's interesting.”
It means:

I wonder → I ask → I investigate → I build → I discover.

The loop never really ends, because every answer can reveal another question:

5. 🧩 Your Character — Rank + Class

Every adventurer has two independent properties:

⚔️ Rank — “What can you currently do?” 🗺️ Class — “Where are you currently exploring?”

F → E → D → C → B → A → S

  • Represents demonstrated capability and contribution.
  • Not intelligence, not popularity, not human worth.
  • Definitely not how loudly someone talks in Telegram. 😂
  • Current state only: You can grow, change direction, and level up.

Status: Still under construction. Criteria will be democratically shaped with the guild members.

Current Active Classes:

  • 🖥️ Frontend
  • ⚙️ Backend
  • 🤖 AI
  • ⛓️ Blockchain
  • 🌐 Web
  • 📱 App
  • 🔌 Electronics
  • 🎨 Civil Design
  • ...and uncharted territories discovered in the wild.

Independence Rule: RANK = Capability  |  CLASS = Territory
Example Character: C Rank · AI | A Rank · Backend | F Rank · Blockchain

There is no contradiction. You can be powerful in one territory and an absolute novice in another.

7. 🧠 The Engineer's Mind — Model Before Syntax

We don't want people who can only memorize syntax. We want people who can look at a machine and ask: “What is actually happening?”

🧠 “A software engineer must learn to take systems apart and build systems back up.”

8. 🧪 Break Things — That's Where Learning Starts

You are allowed to be wrong here. Write terrible code, pick the wrong architecture, crash the program. The enemy is learning nothing from it.

Prediction ≠ Reality ⇒ DATA

The most useful moment is when reality challenges your mental model.

🗣️ Socratic Learning Loop

         +-------> ❓ Question
         |            |
         |            v
         |         🧠 Model

         |            |
         +------------+

Goal: Better models, not simply more information.
